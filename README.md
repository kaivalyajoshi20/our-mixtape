# Our Mixtape ♥ — V2

A romantic, mobile-first mixtape experience built for two.

## Stack
- React 19
- Vite
- Lucide icons
- CSS animations/layout
- Designed to deploy cleanly on Render

## V2 direction
- Song creation and personal notes
- Reorderable playlist UI foundation
- Shareable mixtape foundation
- Photo/memory storytelling
- Love-letter section
- Responsive mobile + desktop experience
- Prepared for Spotify/YouTube integrations and a Railway API

## Run locally
```bash
npm install
npm run dev
```

## Deployment
Render can build the frontend with:
- Build command: `npm install && npm run build`
- Publish directory: `dist`

Railway will host the future API/database layer separately.
